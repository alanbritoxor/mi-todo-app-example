# 📝 Mi Todo App - Ejemplo Práctico MCP GitHub

Una aplicación de lista de tareas moderna y responsive creada como ejemplo práctico del uso del MCP (Model Context Protocol) de GitHub.

## 🚀 Características

- ✅ Agregar nuevas tareas
- 🔄 Marcar tareas como completadas
- 🗑️ Eliminar tareas
- 📊 Contador de tareas totales y completadas
- 💾 Persistencia de datos en localStorage
- 📱 Diseño responsive y moderno

## 🛠️ Tecnologías utilizadas

- **HTML5** - Estructura semántica
- **CSS3** - Estilos modernos con gradientes y transiciones
- **JavaScript ES6+** - Lógica de la aplicación con clases
- **LocalStorage** - Persistencia de datos en el navegador

## 🎨 Características del diseño

- Gradiente de fondo atractivo
- Sombras y bordes redondeados
- Animaciones suaves en hover
- Diseño centrado y responsive
- Iconos emoji para mayor atractivo visual

## 📦 Instalación y uso

1. Clona este repositorio:
   ```bash
   git clone https://github.com/alanbritoxor/mi-todo-app-example.git
   ```

2. Abre el archivo `index.html` en tu navegador web

3. ¡Empieza a agregar tus tareas!
